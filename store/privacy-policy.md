# Refined WhatsApp™ Web Privacy Policy

Effective date: November 23, 2026

Refined WhatsApp™ Web is a browser extension that customizes the layout and on-screen privacy presentation of WhatsApp Web.

## Data collection

Refined WhatsApp™ Web does not collect, transmit, sell, or share personal data or usage data. It contains no analytics, advertising, tracking, telemetry, or remote code.

## Page access

Refined WhatsApp™ Web runs only on `https://web.whatsapp.com/*`. It reads the visible page structure needed to locate interface elements such as the chat list, filter tabs, navigation buttons, and message surfaces. This processing happens locally in the browser. The extension does not copy, store, or transmit messages, media, or account information, and it never transmits anything it reads.

## Local preferences and chat tools

Refined WhatsApp™ Web uses Chrome’s local extension storage to remember settings such as panel width, hidden interface elements, shortcut preferences, and privacy blur options.

Its chat tools also keep, in that same local storage, the names of chats the user chooses to work with: chats they pin, chats they set a reminder on (with the reminder time), the chats they recently opened (for the command palette), and chats that showed an unread @mention, with their unread counts. A chat name can be a phone number when the contact is not saved. Profile photos are shown from WhatsApp’s page but never stored. All of this stays on the current browser profile, is never transmitted, and is removed when the user unpins a chat, clears a reminder, or removes the extension’s data. Each tool can be turned off under Tools in the settings.

## Permissions

- **storage**: keeps the preferences and chat-tool data described above on this device.
- **alarms**: wakes the extension when a chat reminder is due, so it can mark the chat and update the toolbar badge.
- **notifications** (optional, requested only when the user turns on Reminder notifications): shows a system notification for a due reminder. Declining keeps every other feature working.

## Network activity

Refined WhatsApp™ Web does not send network requests and does not communicate with a developer-controlled server or third party.

## Changes

If the extension’s data practices change, this policy and the Chrome Web Store privacy disclosures will be updated before the change is released.
