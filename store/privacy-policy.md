# Refined WhatsApp™ Web Privacy Policy

Effective date: August 7, 2026

Refined WhatsApp™ Web is a browser extension that customizes the layout and on-screen privacy presentation of WhatsApp Web.

## Data collection

Refined WhatsApp™ Web does not collect, transmit, sell, or share personal data or usage data. It contains no analytics, advertising, tracking, telemetry, or remote code.

## Page access

Refined WhatsApp™ Web runs only on `https://web.whatsapp.com/*`. It reads the visible page structure needed to locate interface elements such as the chat list, filter tabs, navigation buttons, and message surfaces. This processing happens locally in the browser. The extension does not copy, store, or transmit messages, contacts, phone numbers, media, folder names, or account information.

## Local preferences

Refined WhatsApp™ Web uses Chrome’s local extension storage to remember settings such as panel width, hidden interface elements, shortcut preferences, and privacy blur options. These preferences remain on the current browser profile unless the user removes the extension data.

## Network activity

Refined WhatsApp™ Web does not send network requests and does not communicate with a developer-controlled server or third party.

## Changes

If the extension’s data practices change, this policy and the Chrome Web Store privacy disclosures will be updated before the change is released.

## Contact

For privacy questions, contact the publisher through the support channel shown on the Chrome Web Store listing.
