# WhatsApp Web Refined Privacy Policy

Effective date: August 7, 2026

WhatsApp Web Refined is a browser extension that customizes the layout and on-screen privacy presentation of WhatsApp Web.

## Data collection

WhatsApp Web Refined does not collect, transmit, sell, or share personal data or usage data. It contains no analytics, advertising, tracking, telemetry, or remote code.

## Page access

WhatsApp Web Refined runs only on `https://web.whatsapp.com/*`. It reads the visible page structure needed to locate interface elements such as the chat list, filter tabs, navigation buttons, and message surfaces. This processing happens locally in the browser. The extension does not copy, store, or transmit messages, contacts, phone numbers, media, folder names, or account information.

## Local preferences

WhatsApp Web Refined uses Chrome’s local extension storage to remember settings such as panel width, hidden interface elements, shortcut preferences, and privacy blur options. These preferences remain on the current browser profile unless the user removes the extension data.

## Network activity

WhatsApp Web Refined does not send network requests and does not communicate with a developer-controlled server or third party.

## Changes

If the extension’s data practices change, this policy and the Chrome Web Store privacy disclosures will be updated before the change is released.

## Contact

For privacy questions, contact the publisher through the support channel shown on the Chrome Web Store listing.
