# Chrome Web Store listing

## Product name

Pane

## Summary

Make WhatsApp Web calmer and more private with native-feeling layout controls, privacy blur, and keyboard shortcuts.

## Category

Productivity

## Detailed description

Pane gives you thoughtful control over WhatsApp Web without making it feel like a different app.

Choose where chat filters live, resize the chat list to suit your screen, hide interface elements you do not use, and protect sensitive conversations with a configurable privacy blur. Every control follows the visual language and interaction patterns already used by WhatsApp Web.

Key features:

- Move chat filters into the existing navigation sidebar or keep the native tabs.
- Drag to resize the chat panel and save your preferred width.
- Hide message previews, the notification prompt, Meta AI, or Channels.
- Blur chat previews, opened messages, media, names, and profile photos.
- Reveal protected content only when you hover over it.
- Use platform-aware keyboard shortcuts for common actions.
- Change settings from a drawer inside WhatsApp Web.

Private by design:

Pane contains no analytics, ads, tracking, or remote code. It does not collect or transmit messages, contacts, phone numbers, media, folder names, or usage data. Your preferences stay in local browser storage.

Pane is an independent extension and is not affiliated with, endorsed by, or sponsored by WhatsApp or Meta. WhatsApp is a trademark of WhatsApp LLC.

## Privacy dashboard answers

**Single purpose:** Customize the layout and on-screen privacy presentation of WhatsApp Web according to user-selected preferences.

**`storage` justification:** Stores the user’s Pane preferences locally in the browser so they persist between WhatsApp Web sessions.

**Host permission justification:** Runs only on `https://web.whatsapp.com/*` to add the selected layout controls and privacy presentation to that page.

**Remote code:** No.

**Data collection:** None. Pane does not collect, sell, or transmit user data.

## Reviewer test instructions

1. Install the unpacked extension and open `https://web.whatsapp.com/`.
2. Sign in to WhatsApp Web with a test account.
3. Use the new Settings button in the left navigation to open Pane.
4. Toggle the chat-folder location, privacy options, and hidden navigation options.
5. Enable “Resizable chat panel” and drag the right edge of the chat list.
6. Confirm the toolbar popup can pause and reactivate Pane.

No additional credentials or external service are required beyond access to WhatsApp Web.
